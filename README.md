# ChronoSprint – Android app

Your `revision_diary.html` packaged as a native Android app with [Capacitor](https://capacitorjs.com).
Everything runs offline: Tailwind CSS and the Inter / JetBrains Mono fonts are bundled, no CDN needed.

## What changed from the HTML file
| Web version | Android version |
|---|---|
| Tailwind + Google Fonts from the internet | Compiled/bundled into the app (works offline) |
| "Download JSON Backup" (browser download) | Writes the file, then opens the Android share sheet (save to Drive/Files, WhatsApp, email…) |
| Restore from JSON | Same – uses the Android file picker |
| Print daily sheet (`window.print`) | Shares today's checklist as text (paste into Keep/WhatsApp/notes) |
| Esc key closes dialogs | Back button/gesture closes dialogs, then returns to Calendar, then exits |

Your data is stored inside the app (same `localStorage` model as the HTML). Use **Backup & Restore** before uninstalling or switching phones.

## Get an APK – option A: no installs (GitHub)
1. Create a new GitHub repository and upload/push this folder.
2. Open the **Actions** tab → *Build Android APK* → **Run workflow** (it also runs on every push).
3. When it finishes, download the **ChronoSprint-debug-apk** artifact, unzip it, and install `app-debug.apk` on your phone (allow "install unknown apps").

## Option B: Android Studio / command line
Requirements: Node 22+, JDK 21, Android Studio (or the Android SDK).
```bash
npm install
npm run sync          # builds web assets and copies them into android/
npx cap open android  # then Run ▶ in Android Studio
# or, from the command line:
cd android && ./gradlew assembleDebug
# APK: android/app/build/outputs/apk/debug/app-debug.apk
```

## Editing the app
* Edit `src/revision_diary.original.html` (the app), `src/native.js` (Android-only bridge), then `npm run sync`.
* App id: `com.chronosprint.app` (change in `capacitor.config.json` **before** first release).
* Launcher icon / splash are generated by `python3 scripts/make-icons.py`.

## Releasing to Google Play (later)
The debug APK is for personal use. For the Play Store you need a signed release **AAB**:
create a keystore, then `./gradlew bundleRelease` (see Android Studio → Build → Generate Signed Bundle). Keep the keystore safe.
